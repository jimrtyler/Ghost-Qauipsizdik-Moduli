# 👻 Ghost Қауіпсіздік Модулі
**PowerShell Негізіндегі Windows және Azure Қауіпсіздік Нығайту Құралы**

> **Windows соңғы нүктелері мен Azure ортасы үшін проактивті қауіпсіздік нығайту.** Ghost қажетсіз қызметтер мен хаттамаларды өшіру арқылы жалпы шабуыл векторларын азайтуға көмектесетін PowerShell негізіндегі нығайту функцияларын ұсынады.

## ⚠️ Маңызды Ескертулер

**ТЕСТІЛЕУ ҚАЖЕТ**: Ghost-ты әрқашан өндірістік емес ортада алдымен тестілеңіз. Қызметтерді өшіру заңды бизнес функцияларына әсер етуі мүмкін.

**ЕШҚАНДАЙ КЕПІЛДІКТЕР ЖОҚ**: Ghost жалпы шабуыл векторларын мақсатқа алса да, ешқандай қауіпсіздік құралы барлық шабуылдарды болдырмай алмайды. Бұл кешенді қауіпсіздік стратегиясының бір компоненті.

**ЖҰМЫС ӘСЕРІ**: Кейбір функциялар жүйе функционалдылығына әсер етуі мүмкін. Орналастыру алдында әрбір параметрді мұқият қарап шығыңыз.

**КӘСІБИ БАҒАЛАУ**: Өндірістік ортасы үшін параметрлердің ұйымыңыздың қажеттіліктеріне сәйкес келетінін қамтамасыз ету үшін қауіпсіздік мамандарымен кеңесіңіз.

## 📊 Қауіпсіздік Ландшафты

Ransomware зияны **2025 жылы 57 миллиард долларға** жетті, зерттеулер көптеген табысты шабуылдар негізгі Windows қызметтері мен қате конфигурацияларды пайдаланатынын көрсетеді. Жалпы шабуыл векторлары мыналарды қамтиды:

- **Ransomware оқиғаларының 90%-ы** RDP пайдалануын қамтиды
- **SMBv1 осалдықтары** WannaCry мен NotPetya сияқты шабуылдарға мүмкіндік берді
- **Құжат макростары** зиянды бағдарламаларды жеткізудің негізгі әдісі болып қала береді
- **USB негізіндегі шабуылдар** ауа-саңылаулы желілерді мақсатқа алуды жалғастыруда
- **PowerShell дұрыс пайдаланбау** соңғы жылдары айтарлықтай артты

## 🛡️ Ghost Қауіпсіздік Функциялары

Ghost **16 Windows нығайту функциясын** және **Azure қауіпсіздік интеграциясын** ұсынады:

### Windows Соңғы Нүкте Нығайту

| Функция | Мақсаты | Ескерулер |
|----------|---------|----------------|
| `Set-RDP` | Қашықтағы жұмыс үстелі қолжетімділігін басқарады | Қашықтағы әкімшілендіруге әсер етуі мүмкін |
| `Set-SMBv1` | Мұраға қалған SMB хаттамасын басқарады | Өте ескі жүйелер үшін қажет |
| `Set-AutoRun` | AutoPlay/AutoRun басқарады | Пайдаланушы ыңғайлылығына әсер етуі мүмкін |
| `Set-USBStorage` | USB сақтау құрылғыларын шектейді | Заңды USB пайдалануына әсер етуі мүмкін |
| `Set-Macros` | Office макро орындауын басқарады | Макро қосылған құжаттарға әсер етуі мүмкін |
| `Set-PSRemoting` | PowerShell қашықтан басқаруды басқарады | Қашықтағы басқаруға әсер етуі мүмкін |
| `Set-WinRM` | Windows Remote Management басқарады | Қашықтағы әкімшілендіруге әсер етуі мүмкін |
| `Set-LLMNR` | Есім шешу хаттамасын басқарады | Әдетте өшіру қауіпсіз |
| `Set-NetBIOS` | TCP/IP үстіндегі NetBIOS басқарады | Мұраға қалған қосымшаларға әсер етуі мүмкін |
| `Set-AdminShares` | Әкімшілік бөлісулерді басқарады | Қашықтағы файл қолжетімділігіне әсер етуі мүмкін |
| `Set-Telemetry` | Деректер жинауды басқарады | Диагностикалық қабілеттерге әсер етуі мүмкін |
| `Set-GuestAccount` | Қонақ есептік жазбасын басқарады | Әдетте өшіру қауіпсіз |
| `Set-ICMP` | Ping жауаптарын басқарады | Желі диагностикасына әсер етуі мүмкін |
| `Set-RemoteAssistance` | Қашықтағы көмекті басқарады | Көмек үстелі жұмысына әсер етуі мүмкін |
| `Set-NetworkDiscovery` | Желі ашуды басқарады | Желі шолуына әсер етуі мүмкін |
| `Set-Firewall` | Windows Firewall басқарады | Желі қауіпсіздігі үшін маңызды |

### Azure Бұлт Қауіпсіздігі

| Функция | Мақсаты | Талаптар |
|----------|---------|--------------|
| `Set-AzureSecurityDefaults` | Негізгі Azure AD қауіпсіздігін қосады | Microsoft Graph рұқсаттары |
| `Set-AzureConditionalAccess` | Қолжетімділік саясаттарын конфигурациялайды | Azure AD P1/P2 лицензиялау |
| `Set-AzurePrivilegedUsers` | Ерекше құқықты есептік жазбаларды аудиттейді | Жаһандық әкімші рұқсаттары |

### Кәсіпорын Орналастыру Опциялары

| Әдіс | Пайдалану Жағдайы | Талаптар |
|--------|----------|--------------|
| **Тікелей Орындау** | Тестілеу, кіші орталар | Жергілікті әкімші құқықтары |
| **Group Policy** | Домен орталары | Домен әкімшісі, GP басқаруы |
| **Microsoft Intune** | Бұлтта басқарылатын құрылғылар | Intune лицензиялау, Graph API |

## 🚀 Жылдам Бастау

### Қауіпсіздік Бағалау
```powershell
# Ghost модулін жүктеу
Invoke-WebRequest 'https://raw.githubusercontent.com/jimrtyler/Ghost/main/Ghost.ps1' -OutFile .\Ghost.ps1
Get-Content .\Ghost.ps1
. .\Ghost.ps1

# Ағымдағы қауіпсіздік позициясын тексеру
Get-Ghost
```

### Негізгі Нығайту (Алдымен Тестілеңіз)
```powershell
# Қажетті нығайту - алдымен зертханалық ортада тестілеңіз
Set-Ghost -SMBv1 -AutoRun -Macros

# Өзгерістерді қарап шығу
Get-Ghost
```

### Кәсіпорын Орналастыру
```powershell
# Group Policy орналастыру (домен орталары)
Set-Ghost -SMBv1 -AutoRun -GroupPolicy

# Intune орналастыру (бұлтта басқарылатын құрылғылар)
Set-Ghost -SMBv1 -RDP -USBStorage -Intune
```

## 🔍 Функция Егжей-тегжейлері

### Негізгі Нығайту Функциялары

#### Желі Қызметтері
- **RDP**: Қашықтағы жұмыс үстелі қолжетімділігін блоктайды немесе портты кездейсоқ етеді
- **SMBv1**: Мұраға қалған файл бөлісу хаттамасын өшіреді
- **ICMP**: Барлау үшін ping жауаптарын алдын алады
- **LLMNR/NetBIOS**: Мұраға қалған есім шешу хаттамаларын блоктайды

#### Қосымша Қауіпсіздігі  
- **Макростар**: Office қосымшаларында макро орындауды өшіреді
- **AutoRun**: Алмалы-салмалы тасушылардан автоматты орындауды алдын алады

#### Қашықтағы Басқару
- **PSRemoting**: PowerShell қашықтағы сеанстарын өшіреді
- **WinRM**: Windows Remote Management тоқтатады
- **Remote Assistance**: Қашықтағы көмек қосылымдарын блоктайды

#### Қолжетімділік Басқаруы
- **Әкімші Бөлісулері**: C$, ADMIN$ бөлісулерін өшіреді
- **Қонақ Есептік Жазбасы**: Қонақ есептік жазбасының қолжетімділігін өшіреді
- **USB Сақтау**: USB құрылғы пайдалануын шектейді

### Azure Интеграциясы
```powershell
# Azure жалға берушіге қосылу
Connect-AzureGhost -Interactive

# Қауіпсіздік әдепкі параметрлерін қосу
Set-AzureSecurityDefaults -Enable

# Шартты қолжетімділікті конфигурациялау
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# Ерекше құқықты пайдаланушыларды аудиттеу
Set-AzurePrivilegedUsers -AuditOnly
```

### Intune Интеграциясы (v2-де жаңа)
```powershell
# Intune-ге қосылу
Connect-IntuneGhost -Interactive

# Intune саясаттары арқылы орналастыру
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## ⚠️ Маңызды Ескерулер

### Тестілеу Талаптары
- **Зертханалық Орта**: Алдымен барлық параметрлерді оқшауланған ортада тестілеңіз
- **Кезеңдік Орналастыру**: Мәселелерді анықтау үшін біртіндеп іске асырыңыз
- **Кері Қайтару Жоспары**: Қажет болса өзгерістерді кері қайтара алатыныңызды қамтамасыз етіңіз
- **Құжаттама**: Сіздің ортаңыз үшін жұмыс істейтін параметрлерді жазып алыңыз

### Ықтимал Әсер
- **Пайдаланушы Өнімділігі**: Кейбір параметрлер күнделікті жұмыс ағынына әсер етуі мүмкін
- **Мұраға Қалған Қосымшалар**: Ескі жүйелерге белгілі хаттамалар қажет болуы мүмкін
- **Қашықтағы Қолжетімділік**: Заңды қашықтағы әкімшілендіруге әсерді қарастырыңыз
- **Бизнес Процестері**: Параметрлердің маңызды функцияларды бұзбайтынын тексеріңіз

### Қауіпсіздік Шектеулері
- **Тереңдіктегі Қорғаныс**: Ghost қауіпсіздіктің бір қабаты, толық шешім емес
- **Үздіксіз Басқару**: Қауіпсіздік үздіксіз мониторинг пен жаңартуларды талап етеді
- **Пайдаланушы Дайындығы**: Техникалық басқару қауіпсіздік хабардарлығымен жұптасуы керек
- **Қауіп-қатер Эволюциясы**: Жаңа шабуыл әдістері ағымдағы қорғанысты айналып өтуі мүмкін

## 🎯 Шабуыл Сценарийлерінің Мысалдары

Ghost жалпы шабуыл векторларын мақсатқа алса да, нақты алдын алу дұрыс енгізу мен тестілеуге байланысты:

### WannaCry Стиліндегі Шабуылдар
- **Азайту**: `Set-Ghost -SMBv1` осал хаттаманы өшіреді
- **Ескеру**: SMBv1 қажет ететін мұраға қалған жүйелер жоқ екенін қамтамасыз етіңіз

### RDP Негізіндегі Ransomware
- **Азайту**: `Set-Ghost -RDP` қашықтағы жұмыс үстелі қолжетімділігін блоктайды
- **Ескеру**: Балама қашықтағы қолжетімділік әдістері қажет болуы мүмкін

### Құжат Негізіндегі Зиянды Бағдарлама
- **Азайту**: `Set-Ghost -Macros` макро орындауды өшіреді
- **Ескеру**: Заңды макро қосылған құжаттарға әсер етуі мүмкін

### USB Арқылы Жеткізілетін Қауіптер
- **Азайту**: `Set-Ghost -USBStorage -AutoRun` USB функционалдылығын шектейді
- **Ескеру**: Заңды USB құрылғы пайдалануына әсер етуі мүмкін

## 📚 Ең Жақсы Тәжірибелер

### Орналастыру Алдында
1. **Ағымдағы Жағдайды Құжаттау**: Өзгерістер алдында `Get-Ghost` іске қосыңыз
2. **Мұқият Тестілеу**: Өндірістік емес ортада растаңыз
3. **Кері Қайтару Жоспарлау**: Әрбір параметрді қалай кері қайтаруды біліңіз
4. **Қызығушылық Танытатын Тараптарды Қарау**: Бизнес бөлімдері өзгерістерді мақұлдайтынын қамтамасыз етіңіз

### Орналастыру Кезінде
1. **Кезеңдік Тәсіл**: Алдымен пилоттық топтарға орналастырыңыз
2. **Әсерді Мониторингтеу**: Пайдаланушы шағымдары немесе жүйе мәселелерін байқаңыз
3. **Мәселелерді Құжаттау**: Болашақ анықтама үшін кез келген мәселелерді жазып алыңыз
4. **Өзгерістерді Хабарлау**: Қауіпсіздік жақсартулары туралы пайдаланушыларға хабарлаңыз

### Орналастыру Кейін
1. **Тұрақты Бағалау**: Параметрлерді тексеру үшін мерзімді түрде `Get-Ghost` іске қосыңыз
2. **Құжаттаманы Жаңарту**: Қауіпсіздік конфигурацияларын ағымдағы күйде ұстаңыз
3. **Тиімділікті Қарау**: Қауіпсіздік оқиғаларын мониторингтеңіз
4. **Үздіксіз Жақсарту**: Қауіп-қатер ландшафты негізінде параметрлерді реттеңіз
